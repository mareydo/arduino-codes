\doxysubsection*{A\+B\+O\+UT}

Simple alarm detecting vibrations from sensor(can be changed for any type of sensor). Uses S\+MS to comunicate with set up mobile number. After init waits for init\+S\+MS in format\+: +123456789012 -\/ 0000 (number -\/ password) and accepts comands only from given \char`\"{}number\char`\"{} and deactivates alarm only by given \char`\"{}password\char`\"{}
