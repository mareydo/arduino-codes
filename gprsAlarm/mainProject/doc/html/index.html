BI-ARD SMS Alarm Documentation

ABOUT

Simple alarm detecting vibrations from sensor(can be changed for any type of sensor). Uses SMS to comunicate with set up mobile number. After init waits for initSMS in format: +123456789012 - 0000 (number - password) and accepts comands only from given "number" and deactivates alarm only by given "password"

LIBRARIES

using AltSoftSerial and TinyGPS libraries zip files included in folder ./libraries

AltSoftSerial TinyGPS++

PIN LAYOUT

Arduino Periferies
RELAY=6 RELAY COM
PWR=7 MODULE PWR_KEY
RX=8 MODULE TX
TX=9 MODULE RX

UI

Commands

  • #GPS - show gps coords
  • #ALARM - turn alarm on
  • password - turn alarm off

I/O

  • if fatal error happens during init, builtin led turns on
  • if init is correct, builtin led blinks 10 times
  • comunicates only with given number
  • comunicates only trough SMS


MODULE LIMITATIONS

during init is safer to watch module built in LED to check correct turn on
if no sms comes, send command again
comunication is set on 9600bauds, can be changed with AT+IPR=9600 (factory value is 115200 <- not safe to use)
module need 2A at peak <= needs to be plugged separatly, wont keeep many external chargers on by itself
